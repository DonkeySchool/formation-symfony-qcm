# Formation Symfony — QCM Jour 1

QCM interactif d'évaluation des acquis (niveau avancé, façon préparation à une
certification PHP/Symfony) couvrant le **Jour 1** de la formation
*Symfony – Avancé / Bonnes pratiques PHP & Symfony* (DonkeyCode × DonkeySchool).

## Contenu (29 questions)

- **PHP avancé** : typage strict & coercition, opérateurs (`??` / `?:`), `match` (`$var` strict et `match(true)`), nullsafe, `#[\SensitiveParameter]`, late static binding, attributs natifs, constructor promotion / `readonly`.
- **SOLID** en situation (SRP, OCP, LSP, ISP, DIP).
- **Design patterns** opérationnels (Adapter vs Facade, Factory vs Strategy, Observer, DTO vs groupes de sérialisation).
- **Composer / SemVer / PSR** (caret `^0.4`, tilde, `install` vs `update`, `composer.lock`, PSR-4).
- **Symfony — Kernel & Events** (cycle de vie, `terminate`, `view`, `exception`, Subscriber vs Listener).

Chaque question est corrigée immédiatement avec une explication sourcée
(php.net, symfony.com, getcomposer.org, php-fig.org). L'ordre des réponses
est mélangé à chaque passage.
